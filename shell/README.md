# Karchy shell

The Karchy desktop runs in one long-lived Quickshell process. Its bar, panels, overlays, menus, and services are plugins hosted by `shell.qml`.

- [Shell design foundations](../docs/architecture.md#shell-design-foundations): the tokens, shared components, panel and window patterns, the bar and the icons, which are also the conventions for changing the desktop.
- [First-party plugins](plugins/README.md): bundled plugin IDs, kinds, and entry points.
- [Themes](../docs/architecture.md#themes) and the [theme reference](../skills/karchy/references/themes.md): where themes live, the templates, and the commands.
