# karchy's docs

## Using karchy

- [Installing karchy](installing.md): download the ISO, write it to a USB stick, answer the form. Also Secure Boot, disk encryption and installing from an answer file.
- [Using karchy](using.md): the first keys, the menu, Settings, apps, updates, themes and accounts.
- [When karchy does not boot](recovery.md): snapshots, the fallback kernel, getting in from the install stick, and what to do when someone can't sign in.
- [Keybindings](keybindings.md): every default key.

## Working on karchy

- [Working on karchy](development.md): dev mode, building the packages and the ISO, testing in a VM.
- [Architecture](architecture.md): how the repository, the packages and the shell fit together.
- [Packaging](../packaging/README.md): how the packages are built, versioned and published.
- [Maintenance](maintenance.md): what keeps an installed machine current, the package set, migrations and what needs a person.
